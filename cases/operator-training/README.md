# Operator training

Plants prepared for the Operator Training Simulator: a dynamic flowsheet with controllers, gauges with alarm
limits, interlocks, operator screens and a pack of scored scenarios stored inside the file. The training
features need the OTS extender (DWSIM Patreon level 3, Classic interface); the flowsheets themselves open in any
DWSIM 10.2.9 or later.
